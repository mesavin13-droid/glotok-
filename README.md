# Глоток — доставка напитков по Новосибирску

Собственный каталог товаров и доставка владельцем, не маркетплейс.

## Состояние
Это начальная точка репозитория. Рабочий исходный комплект проекта готовится отдельно; перед запуском необходимо загрузить весь комплект приложения, настроить переменные окружения и подключить отдельную базу данных. Проекты «Шабашка» и «Соседи» не использовать.

## Важно
- Не хранить секреты и токены в Git.
- Онлайн-оплата отключена; на MVP предполагается оплата при получении.
- До приёма реальных заказов заполнить и проверить политику обработки персональных данных и требования 152-ФЗ.
- Для заказов с телефонами и адресами отдельно проверить требования к размещению базы и серверов в РФ.
- Не использовать чужие фото/описания товаров без разрешения.

## Следующий этап
Загрузить исходный комплект приложения, проверить тесты, затем выбрать отдельную инфраструктуру и только после проверки подключать Telegram Mini App.
